# Исправления полного аудита — 6 ноября 2026

Применены все 21 подтверждённое замечание аудита рабочей копии `cb19192`.
Первый переход со старой модели ролей не требует восстановления прежних emp/apr:
владелец установки принял это ограничение. Новое чтение ролей не переписывает
исходные назначения; для последующих выпусков введён контракт совместимости.

Проверки финального кода:

- **462 теста прошли**, включая новые проверки отмены, одновременной доставки,
  повторов команд, смены получателей, старых подтверждений, ролей между процессами,
  совместимости форматов, lock-файлов, восстановления пространств и пакетной очистки.
- Ruff: `All checks passed!`; mypy: `Success: no issues found in 28 source files`.
- Компиляция Python, `sh -n entrypoint.sh`, `git diff --check`, `pip check` прошли.
- pip-audit установленного окружения после обновления Pillow и pip:
  `No known vulnerabilities found`. Это проверка Python-пакетов, не SBOM всей ОС.
- Docker собран. В контейнере без сети и токенов, 2 CPU / 512 МиБ проверены
  импорты, SQLite, PNG/JPEG, HEIC и настоящий ffmpeg/H.264 с превью.
  Для облачного прокси использован временный Dockerfile с CA через BuildKit secret;
  TLS-проверка не отключалась, этот CA не включён в образ.

Для полного применения нужен новый Docker-образ: изменения загрузчика внутри
образа не доставляются одной кнопкой. Команды под `bot` и перенос всех исходников
из `code`: [INSTALL.md — временная пересборка](INSTALL.md#временно-пересборка-после-обновления-кнопкой).

Ограничения: первый старый загрузчик не умеет проверять compatibility.json;
контракт начинает защищать последующие обновления после установки нового образа.
Установка библиотек требует сети и не является атомарным переключением venv.
При потере ответа MAX возможно повторное личное превью; защита публикаций в каналы
отдельная. Не подтверждены реальные разрешения каналов, отображение MAX, нагрузка
и память на предельных видео; работающий VPS этой проверкой не изменяется.
