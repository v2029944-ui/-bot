# HTTPS-адрес для webhook MAX

Webhook пока не включён. Бот продолжает получать события через long polling;
новая постоянная очередь работает с этим способом получения.

При webhook MAX сам отправляет входящие события на публичный HTTPS-адрес бота,
например `https://bot.example.ru/max/webhook`. Это адрес обработчика на сервере,
а не ссылка на профиль бота в MAX. Обычный сайт с дизайном для этого не нужен.

## Где взять адрес

Самый удобный вариант для имеющегося VPS:

1. Взять собственный домен у регистратора либо использовать уже имеющийся домен.
2. В панели DNS добавить поддомен `bot` с записью `A`, указывающей на публичный
   IPv4 вашего VPS. Если используете `AAAA`, IPv6 тоже должен реально работать.
3. На VPS настроить Caddy или Nginx, чтобы запросы к этому имени по HTTPS
   передавались обработчику бота. Для выпуска и продления сертификата можно
   использовать Let's Encrypt; Caddy умеет делать это автоматически.
4. Разрешить входящий HTTPS на порту 443 в настройках VPS и его межсетевого экрана.
   Для выбранного способа выпуска сертификата может понадобиться также порт 80.
5. Добавить обработчик webhook в бот и зарегистрировать адрес через API MAX.
   Проверять секрет из `X-Max-Bot-Api-Secret`, сохранять событие в очередь и лишь
   затем отвечать MAX `200 OK`. Долгую обработку файлов выполнять отдельно.

Одна DNS-запись сама по себе webhook не включает: нужны также сертификат,
приём запросов на сервере и поддержка этого режима в коде. При переходе polling
для того же бота выключают. Эти изменения будут отдельным этапом.

## Стоимость

| Что нужно | Как оплачивается |
| --- | --- |
| Уже используемый VPS | Продолжается обычная оплата VPS; отдельный сервер обычно не нужен |
| Сертификат Let's Encrypt | Бесплатно, требуется автоматическое продление |
| Caddy или Nginx | Бесплатное программное обеспечение |
| Поддомен существующего домена | Обычно без дополнительной платы, если есть управление DNS |
| Новый собственный домен | Обычно ежегодная оплата; сравнивайте цену продления, а не только первого года |
| Бесплатный поддомен DNS-сервиса | Возможен без оплаты, но имя и условия зависят от сервиса |

Таким образом, если у вас уже есть VPS и домен, HTTPS для бота обычно можно
настроить без дополнительных регулярных расходов. Покупать платный SSL-сертификат
не требуется. Бесплатный туннель тоже может дать HTTPS-адрес, но временные адреса
меняются; для постоянной работы нужен стабильный адрес и постоянно работающий туннель.

Перед настройкой понадобятся имя домена или выбранного бесплатного поддомена,
доступ к его DNS и доступ к VPS. В текущей версии покупать или настраивать домен
для запуска бота не обязательно.

Официальный метод регистрации: [POST /subscriptions](https://dev.max.ru/docs-api/methods/POST/subscriptions).
