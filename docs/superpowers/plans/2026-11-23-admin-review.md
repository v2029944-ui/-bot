# Admin Review Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Участники отправляют материалы, администраторы проверяют и публикуют во всех пространствах.
**Architecture:** Сохранить роли member/adm. Общая проверка can_manage_draft разрешает действия только администраторам активного пространства; draft_recipients определяет получателей для всех путей доставки.
**Tech Stack:** Python 3.12, SQLite, httpx, aiogram, pytest.
**Spec:** docs/superpowers/specs/2026-11-23-admin-review-design.md

## Global Constraints

- Не менять схему SQLite, зависимости, статусы каналов и изоляцию пространств.
- Не запускать реальную публикацию, LLM или обновление VPS.
- Сохранять незавершённые материалы и защиту от повторной отправки.

## Review Focus

- Старые кнопки и сохранённый ввод автора не дают прав после обновления.
- Отложенная доставка автора переназначается администратору.
- Отозванная роль администратора проверяется перед доставкой и действием.
- Один администратор двух пространств публикует в правильные группы при совпадающих ID постов.
- Участник не получает черновики, напоминания или список действий с постами.
