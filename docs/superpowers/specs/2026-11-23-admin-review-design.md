# Проверка постов администратором

Согласованный сценарий: во всех пространствах участники только отправляют материалы.
Администраторы своего пространства получают черновики, редактируют, отклоняют и
подтверждают публикацию в закреплённые за пространством группы MAX/Telegram.
Один человек может администрировать несколько пространств; права в каждом задаются
существующей ролью. Для одного проверяющего в команде оставляют одного администратора.

Рассмотрены настройка каждого пространства и обязательный порядок во всём боте.
Пользователь выбрал обязательный порядок. Новая роль или настройка не нужны.

Проверка прав единая для новых и старых кнопок, прямых операций и сохранённого ввода.
Получатели черновиков, напоминаний и отложенной доставки — действующие администраторы.
Участники сохраняют приём материалов, настройки уведомлений и сообщения о результате.
Существующие незавершённые материалы сохраняются и доступны администраторам.
Очереди, версии, одноразовые подтверждения и защита частичных публикаций сохраняются.
Формат SQLite, зависимости и механизм обновления не меняются. VPS не затрагивается.
