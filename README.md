# Посты из MAX в MAX и Telegram

Сотрудник отправляет боту в личном чате MAX фото, видео или альбом с подписью.
Нейросеть готовит пост; проверяющий редактирует его и подтверждает публикацию
в группы MAX и Telegram. Все рабочие действия выполняются в MAX.

- [Установка, резервные копии и обновление](INSTALL.md) — команды под `root` и `bot`.
- [Независимые пространства для нескольких команд](SPACES.md).
- [Устройство кода, очереди и ограничения](ARCHITECTURE.md).
- [Webhook и HTTPS](WEBHOOK.md) — текущий бот использует long polling.

## Материалы и согласование

Можно отправить одно фото, одно видео или до **10 фото и видео одним сообщением**
с общей подписью. Отдельные сообщения не объединяются. Общий лимит альбома —
100 МиБ, каждого видео — по умолчанию 49 МиБ и 180 секунд. Видео преобразуется
в MP4/H.264. Нейросеть получает подпись и кадры, без расшифровки речи.

У проверяющего три кнопки:

- **Отклонить** — подтверждение и необязательная причина для сотрудника.
- **Опубликовать** — отдельное подтверждение отправки в оба канала.
- **Изменить** — заново, с комментарием, править самому, выбрать длину поста.

Выбор длины создаёт новый вариант: короткий — примерно 150–300 знаков,
средний — 300–800, подробный — 800–1500. Недостающие факты не выдумываются.
Меню изменения и выбора длины заменяет кнопки под постом; если MAX отклоняет
редактирование, приходит отдельное меню. Мигание фото зависит также от клиента MAX.
Кнопки обработанных и устаревших вариантов убираются фоновой очисткой.

Незавершённая ручная правка, комментарий, причина отклонения, ввод правила и
настройки ссылки **сохраняются после перезапуска** до 7 дней. `/cancel` отменяет
текущий ввод, `/menu` открывает меню. Правка сохраняет ID и версию черновика:
если другой проверяющий уже изменил или опубликовал пост, старый ввод его не заменит.

После подтверждения MAX получает сообщение со всеми вложениями, Telegram — фото,
видео или медиагруппу. Длинный текст в Telegram отправляется после медиа отдельно.
При частичной публикации успешный канал не повторяется. Если результат отправки
неизвестен из-за сетевого сбоя, сначала проверьте канал и затем подтверждайте повтор.
Менять текст после начала частичной публикации нельзя.

## Администратор и участники

У администратора под последним сообщением бота есть «Меню админа».
Через меню доступны участники, заявки, правила, уведомления, пауза, статус,
обработка материалов, ссылки, сравнение моделей и обновление.

«Добавить человека» принимает две строки: числовой ID пользователя MAX и
`сотрудник` или `проверяющий`. Роли существующих участников меняются через «Люди».
Пользователь должен сначала открыть чат с ботом. ID MAX и Telegram отличаются.
В режиме заявок неизвестные пользователи не могут отправлять материалы или
управлять постами; заявка на доступ приходит администратору.

Один бот может обслуживать несколько независимых команд. У каждой — свои
владелец, участники, правила, черновики и группы двух платформ. Владелец работает
в своём пространстве автоматически. Создание: `/admin` → «Рабочие пространства».
Подробности — в [SPACES.md](SPACES.md).

## Правила, ссылка и модели

В «Правилах стиля» задаются требования к текстам. Удаление правил использует
актуальную нумерацию списка. При включённом обучении комментарии проверяющего
могут дополнять постоянные правила; `LEARN_RULES=0` это отключает.

В «Ссылке в постах» задайте текст, HTTPS-адрес для каждой платформы и маркер,
по умолчанию `{bot}`. Например, правило: «В конце пиши: Для заказа используйте
нашего {bot}», текст ссылки — «бота». Маркер станет кликабельным словом прямо
в предложении. Если маркера нет, ссылка добавляется отдельной строкой.

Ссылка сразу видна при согласовании. Настройки фиксируются для варианта поста:
ручная правка сохраняет их, повторная генерация применяет текущие. При копировании
неизменённого заключительного абзаца бот восстанавливает маркер автоматически;
если место ссылки неоднозначно, попросит вставить `{bot}` явно.

«Сравнение моделей» AITunnel выбирает три модели с поддержкой изображений из
публичного каталога: GPT, Claude Sonnet и Gemini Flash. Имена видны под вариантами.
Перед публикацией выберите один вариант. «Заново» при включённом сравнении снова
создаёт три; комментарий и выбор длины после выбора работают с выбранной моделью.
Один материал в этом режиме означает три генерации и соответствующие списания.
При недоступном каталоге режим не включается.

При AITunnel кнопка «Статус» показывает баланс и бюджет ключа, если он настроен.
Проверка доступности нейросети делает небольшой платный запрос. Все пространства
используют общий API-ключ; баланс доступен в основном пространстве.

## Очереди и ресурсы

Входящие материалы и команды сохраняются в SQLite до подтверждения событий MAX.
Повтор события с тем же ID не создаёт ещё один черновик. При временной ошибке
обработки материалов предусмотрено до 8 попыток; затем повтор доступен в
«Обработке материалов». Если черновик уже создан, повторяется его доставка.

По умолчанию обрабатываются до **двух материалов разных пространств одновременно**,
внутри каждого — по одному. `MATERIAL_WORKERS=1` включает последовательную обработку.
Тяжёлая обработка фото и видео выполняется по одной операции на весь процесс;
запросов нейросети одновременно не больше трёх. Это ограничивает расход памяти
и нагрузку на API, в том числе при сравнении моделей.

Команды до четырёх пользователей обрабатываются параллельно, команды одного
человека — по порядку. Получение новых событий не ждёт генерации постов.
Запускайте один экземпляр бота на одну базу и один MAX-токен.

## Хранение

После полной публикации удаляются локальные медиа, превью, текст, исходная подпись
и данные автора. Посты в мессенджерах остаются. В базе сохраняются минимальные
ID, статус и даты для статистики и защиты от дублей.

Необработанные черновики хранятся по умолчанию 7 дней с последней отправки на
согласование. Очистка выполняется при запуске и каждые 6 часов. Временные оригиналы
очереди удаляются после обработки или истечения её семидневного срока.
Состояние ожидаемого ввода не содержит копий текста или медиа; его срок — 7 дней.

Резервная копия должна включать `.env` и **всю папку `data`**, включая пространства.

## Запуск и разработка

Установка и обновление на VPS описаны в [INSTALL.md](INSTALL.md).
При настроенном GitHub обновление доступно кнопкой в MAX; переустановка не нужна.
Для обновления существующей установки новые обязательные параметры `.env` не нужны.

Для разработки нужен Python 3.12:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-dev.txt
.venv/bin/python -m pytest -ra
# После заполнения .env:
.venv/bin/python main.py
```

Тесты используют подставные API и настоящий ffmpeg для коротких роликов.
Права ботов и отображение постов в настоящих группах проверяются отдельно.

Официальные источники: [создание бота MAX](https://dev.max.ru/help/chatbots/),
[Bot API MAX](https://dev.max.ru/docs-api/),
[OpenAPI MAX](https://github.com/max-messenger/api-schema),
[Telegram Bot API](https://core.telegram.org/bots/api).
